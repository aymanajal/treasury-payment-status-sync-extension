# 司库支付状态顺序同步（Chrome 扩展）

在 YonBIP/NCCloud 的“直联支付”列表中，先从列表顶部逐段扫描到筛选结果末尾，累计识别虚拟列表中的行并核对总条数，然后从最后一行开始向上逐条点击“司库支付状态同步”。如果扫描结束后识别数仍小于分页总数，插件会停止且不点击，避免从中间记录开始。

## 安装

1. Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`/Users/fanghongjian/Documents/ChatGPT/司库支付状态同步插件`。
5. 在扩展卡片上确认开关为“开启”；如果之前关闭了，打开开关。
6. 如果已经加载过旧版，在扩展卡片上点“重新加载”。
7. 回到“直联支付”页面并刷新一次。

识别到操作链接后，页面右下角会出现“司库状态顺序同步”面板。
点击工具栏的扩展图标会打开状态弹窗，可查看当前页识别数量并显示或收起页面控制面板。

## 使用

1. 先在系统中选好页签、组织、日期和每页条数。
2. 建议先用少量筛选结果验证；默认每条间隔 4 秒。
3. 点击面板中的“开始”，核对检测数量后确认。
4. 执行期间可以“暂停/继续”或“停止”。
5. 默认检测到页面错误提示时停止，便于人工核对。

## 执行边界

- 只处理当前筛选结果的当前页，不会自动改查询条件或翻页；开始前先从顶部逐段扫描到末尾并核对识别数，确认后从末行开始向上遍历。
- 面板同时显示“当前待点”和“已识别 X/总数”，前者只是当前 DOM 已加载的批次；执行开始时会用分页总数核对，若滚到底仍未识别全量，会标记“需核对”。
- 按列表当前顺序逐条执行，同一单据编号在一次运行中只点击一次。
- “已完成一次点击”仅表示页面点击动作已发出，最终业务结果仍以列表的单据状态、支付状态和后台日志为准。
- 刷新页面会清空插件的本次进度；请勿在运行中刷新或切换筛选条件。
- Chrome 扩展管理页中必须保持本扩展开启；关闭开关后脚本会停止注入。
- 浏览器扩展产生的是网页脚本点击。若目标系统强制校验浏览器原生可信输入，需要改用浏览器调试协议方案。

## 修改适用地址

当前仅注入 `http://192.168.116.150:9080/*`。如果测试或正式环境地址不同，请在 `manifest.json` 的 `matches` 中新增对应地址，然后在扩展管理页点击“重新加载”。
